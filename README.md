# Stroke Risk Prediction System

## Project Overview
This project uses machine learning to predict the risk of stroke based on patient health and demographic information. It aims to support early risk assessment through data analysis and predictive modeling.

## Tools & Technologies
- Python
- Pandas, NumPy
- Scikit-learn, XGBoost
- SHAP
- FastAPI, Streamlit
- Docker

## Project Tasks
- Cleaned and preprocessed patient data.
- Performed exploratory data analysis (EDA).
- Handled class imbalance during model training.
- Trained and evaluated multiple machine learning models.
- Used SHAP to understand important prediction factors.
- Developed an interactive application to generate stroke risk predictions.

## Skills Demonstrated
Data cleaning, EDA, machine learning, model evaluation, feature importance, API development, and deployment.

## Disclaimer
This project is intended for educational purposes and preliminary stroke risk screening only. It is not a medical diagnostic tool and should not replace professional medical advice or evaluation.
